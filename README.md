Anomaly Detection in SMTP Protocol Using Deep Autoencoders
📌 Project Overview

This project presents a deep learning approach for identifying abnormal activities in SMTP (Simple Mail Transfer Protocol) network traffic using an Autoencoder-based model.

The model is trained to understand patterns of legitimate network behavior from the NSL-KDD dataset. When incoming traffic significantly differs from these learned patterns, it is flagged as a potential anomaly, enabling the detection of intrusions and malicious actions.

The implementation highlights the use of unsupervised deep learning techniques for enhancing cybersecurity systems and supporting intelligent intrusion detection mechanisms.
